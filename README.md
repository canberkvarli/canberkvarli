## Now building

<a href="https://apps.apple.com/us/app/ghost-light-monologues/id6804278673"><img src="assets/ghostlight.svg" alt="Ghost Light: find your next audition piece, then rehearse it." width="100%"></a>

**[Ghost Light](https://apps.apple.com/us/app/ghost-light-monologues/id6804278673)** is AI search and rehearsal for actors, on iOS and the [web](https://www.actorrise.com). You describe the monologue you need in plain English and get real matches from 19,000+ pieces. Then you rehearse it with a voice scene partner that waits for your cue.

Ghost Light started on the web as ActorRise. I'm folding both into one name now, with the iOS app leading.

| 2,300+ | 19k+ | iOS + web |
| :-- | :-- | :-- |
| signups | monologues indexed | one backend |

- **Hybrid search.** pgvector embeddings plus trigram text search. The AI finds pieces but never writes or changes the source text.
- **Scene partner.** A voice rehearsal partner that waits for your cue line.
- **Offline saves.** For when you're in the wings with no signal.
- **Production ETL.** Scraping, monologue extraction, AI content analysis and batch embeddings.
